# Module Name: scholarships

## Designated User Roles & Permissions

### 1. Role Name: SPACS Convener
- Description: Primary manager for scholarship policies, final application approvals, award disbursements, and overall committee operations.
- Permissions:
  - Create, update, and manage scholarship types and catalogs.
  - Approve, reject, or request changes on scholarship applications.
  - Institute fund disbursements and oversee merit list generation.
- Remarks: Holds the highest authority in the module for finalizing scholarship awards.

### 2. Role Name: SPACS Assistant
- Description: Administrative user responsible for reviewing and verifying student scholarship applications, and maintaining scholarship records.
- Permissions:
  - View and verify all incoming student scholarship applications.
  - Update application statuses (e.g., to NEEDS_INFO, FORWARDED) after initial screening.
  - Verify uploaded documents like income certificates and undertakings.
- Remarks: Serves as the primary operational checker who bridges the students and the convener.

### 3. Role Name: Student
- Description: Applicant who can browse available scholarships, submit applications, amend pending applications, and track their application status.
- Permissions:
  - View available scholarship types and merit lists.
  - Submit, amend, and withdraw personal scholarship applications.
  - Track application status and view disbursed award details.
- Remarks: Can only access and modify their own securely scoped application and eligibility data.
